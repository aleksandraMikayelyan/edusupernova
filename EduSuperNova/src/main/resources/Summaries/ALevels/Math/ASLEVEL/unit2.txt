INTRODUCTION TO FUNCTIONS
A function is a rule that assigns each element from a set (the domain) to exactly one element in another set (the range)[cite: 49].

MAPPING: The process of associating elements of one set with elements of another.
DOMAIN: The set of all possible input values (x-values) for which the function is defined.
RANGE: The set of all possible output values (y-values) that the function can produce.

TYPES OF MAPPINGS
Mappings can be classified based on how inputs and outputs relate to each other.

- One-to-one: Each input has a unique output, and each output comes from a single input.
- Many-to-one: Different inputs can produce the same output (e.g., f(x) = x^2).
- One-to-many: One input relates to multiple outputs; this is a relation, not a function.

COMPOSITE FUNCTIONS
A composite function is created when one function is applied to the result of another function.

DEFINITION: For two functions f and g, the composite function fg(x) is defined as f(g(x)).

- The order of composition matters; usually, fg(x) is not equal to gf(x).
- For fg(x) to exist, the range of g must be a subset of the domain of f.

INVERSE FUNCTIONS
An inverse function, denoted as f^-1(x), reverses the effect of the original function f(x).

REMEMBER: A function has an inverse if and only if it is a one-to-one mapping.

- The domain of f^-1(x) is the range of f(x).
- The range of f^-1(x) is the domain of f(x).
- To find the inverse, let y = f(x), swap x and y, and solve for y.

TRANSFORMATIONS OF GRAPHS
Graphs of functions can be altered through translations, reflections, and stretches.

Translations:
- y = f(x) + a: Translation by vector (0, a).
- y = f(x - a): Translation by vector (a, 0).

Reflections:
- y = -f(x): Reflection in the x-axis.
- y = f(-x): Reflection in the y-axis.

Stretches (where a > 0):
- y = a f(x): Stretch parallel to the y-axis with factor a.
- y = f(ax): Stretch parallel to the x-axis with factor 1/a.
